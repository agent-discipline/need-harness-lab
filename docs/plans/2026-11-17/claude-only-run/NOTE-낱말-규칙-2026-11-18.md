# 메모 — 이 저장소 문서의 낱말이 바뀌었다 (2026-11-18)

이 작업 폴더로 일하는 세션에게 남기는 메모다. 다른 세션(resume 저장소 세션)이 사용자 지시로 이 저장소의 문서 낱말을 고쳤다. 문서를 다시 쓰거나 고치기 전에 아래를 확인한다.

## 바뀐 것

- **이 저장소의 문서는 바꾸지 않았다.** 실험이 진행 중이고 `payment-settlement/docs/`의 문서가 에이전트 입력물이라, 낱말 치환을 적용했다가 되돌렸다(현재 차이 없음).
- 같은 조직의 다른 실험 저장소(clean-code-llm-experiment, graph-nav-experiment, compare-issue-archive)는 README, ADR, 결론 문서의 낱말을 고쳐 main에 반영했다.

## 이 세션이 할 일

1. 위 문서를 고치기 전에 **파일을 다시 읽는다**. 컨텍스트에 남아 있는 옛 본문으로 덮어쓰지 않는다.
2. 앞으로 쓰는 독자용 문서(README, ADR 본문, 결론 문서)는 같은 낱말로 쓴다. 규칙은 `~/.claude/playbooks/korean-wording.md`(하네스 v4.4에서 추가)이고, 사례 표는 `/home/jun/project/agent-discipline/rules/writing/wording-table.md`다.
3. 다 쓴 뒤 사례 표 왼쪽 열 낱말로 검색해, 표의 뜻으로 쓰인 곳만 고친다.

## 주요 낱말

| 쓰지 않는 말 | 쓰는 말 |
|---|---|
| 기준선, 판정기 | 베이스라인, 정합성 검증기(판정 스크립트) |
| 벽, 무너짐 | 처리량 급락 |
| 꼬리 지연, 튐, 느린 초 | 테일 레이턴시, 스파이크, 스파이크 초 |
| 어긋남, 대조(카운터), 쌍 | 불일치, 보정(배치), 키 |
| 안전망, 한 바퀴, 훑다 | 폴백 스캔, 풀 스캔 1회, 스캔하다 |
| 손잡이 | 설정 옵션 |
| 이긴 쪽, 진 쪽 | 성공한 요청, 실패한 요청 |
| 격벽, 문턱, 칸, 탐침 | 벌크헤드, 기준값, 셀, probe(영어 그대로) |
| 무음 실패, 오염(측정) | 조용한 실패, 측정 노이즈 |

## 바꾸지 않는 것

- 코드 식별자, 설정 키, 테스트 이름, 로그 문자열, 사용자 발언 인용.
- 대조군, 임계 구역, 오탐, 정합성처럼 이미 통용되는 용어. 영어 그대로 쓰는 말(probe, prod, yml, upsert, flush)은 영어로 둔다.
- 작업 원본(명세서, log, 측정 원본).
- **실험 입력물과 고정 입력(frozen-inputs), 조건별 프롬프트, 실행 기록은 낱말 규칙의 대상이 아니다. 실험 도중에 바꾸지 않는다.** 규칙은 새로 쓰는 독자용 문서(README, 결과 보고, 분석)에만 적용한다.
- 하네스 용어 '필수 6칸'은 '셀'로 바꾸지 않는다.
