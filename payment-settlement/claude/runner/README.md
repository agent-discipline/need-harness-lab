# Claude Code 격리 실행기

`init`은 starter를 복사하고 무과금 self-test를 통과해야 run을 만든다. **`turn`은 실제 유료(구독) 호출을 시작한다.** `normalize`는 보존된 이벤트를 공유 adapter로 정규화한다.

## 이미지

`node:22-bookworm-slim` + Temurin 21 JDK + `@anthropic-ai/claude-code@2.1.326` + 훅 의존(jq·flock·git·awk·realpath·python3). `USER node`(uid 1000), `HOME=/home/node`, `CLAUDE_CONFIG_DIR=/home/node/.claude`(0700 — 리뷰어가 PM의 세션 기록을 읽지 못함), 자동 업데이트 비활성. codex는 없다. `/usr/local/bin/fable-review`(`fable-review.sh`)는 3번의 두 번째 리뷰어 클라이언트다: stdin 프롬프트와 현재 디렉터리를 소켓 `/run/fable-review/socket`으로 리뷰어 도우미(`fable_review.py serve`, 별도 계정 `fablereview` uid 2001)에 보내고 stdout 리뷰·종료 코드를 받는다. 도우미만 토큰을 갖고(상속 파이프로 받아 메모리에만), 호출마다 요청 디렉터리를 자기 소유 스냅숏으로 복사(심링크·다른 파일 시스템 불허, 요청자가 스스로 읽을 수 있는 것만, `.git`·`.claude`·`.mcp.json` 제외, 20,000파일·256 MiB 상한, 어긋나면 거부하고 `refused`로 기록)한 뒤 그 안에서 능력 없이(`setpriv --bounding-set=-all --inh-caps=-all --ambient-caps=-all`) 고정 명령 하나(새 `claude -p` 세션, 리뷰어 모델, effort high, `--tools Read,Grep,Glob`, `--setting-sources user --strict-mcp-config`, 리뷰어 config dir `/home/node/.fable-review` — 0700 `fablereview`, 토큰은 파이프로)를 실행한다. 호출자가 끊으면 CLI를 멈추고 `cancelled`로 기록한다(사용량 미관측). 호출마다 시작 전에 `reviewer-calls.log`에 호출·session id를 남기고, 기록 실패(97)·형식 밖 요청(94)·도우미 없음(1·2번, 98)이면 실행을 거부한다. 3번 컨테이너 시작은 `lab-arm3-start`(`lab-arm3-start.sh`, root·능력 넷만 — `SETUID`/`SETGID`: 계정 전환, `SETPCAP`: PM·리뷰어 CLI의 bounding set 비우기, `DAC_READ_SEARCH`: 도우미가 PM의 0700 미러를 복사): 도우미(`DAC_READ_SEARCH`·`SETPCAP`만)를 띄우고, `/workspace`를 소유자로 `chmod o-rwx` 해(리뷰어 CLI가 PM의 작업 폴더를 읽지 못함 — 호스트 쪽 폴더도 770이 됨, 실패 시 exit 92) PM을 `node`(능력·bounding set 0)로 실행하고 토큰은 파이프(`CLAUDE_CODE_OAUTH_TOKEN_FILE_DESCRIPTOR=3`)로만 준다(`docs/runbook.md` 준비 절).

## 명령

```bash
python3 payment-settlement/claude/runner/launch.py init --run-id <id> --arm <1|2|3> --core <1..10> [--harness payment-settlement/claude/harness-source] [--network <compose_default>] [--readiness <file>] [--pilot | --refreeze-smoke]
python3 payment-settlement/claude/runner/launch.py turn --run-id <id> --prompt <file> --env-file <0600 file outside repo> [--resume --kind feedback|answer|recovery] [--max-turns N] [--max-budget-usd X] [--timeout-seconds N (기본 28800 = run 상한, 남은 시간으로 줄임)] --cache-policy observed-cache [--dry-run]
python3 payment-settlement/claude/runner/launch.py normalize --run-id <id>
python3 -m unittest discover -s payment-settlement/claude/runner -v
```

- init: `.runs/<id>/`를 staging에서 조립해 원자적으로 rename한다(실패 시 잔여물 없음). `--pilot`이면 run id가 `claude-pilot-NN`이어야 하고 manifest `pilot=true`가 기록 위치(`docs/pilots/<run id>/`)를 정한다(`record_folder`·`open_record` — 기록 폴더 `run.json`의 `run_id`가 다르면 기록 도구가 거부). 동결 파일은 `--readiness`로 명시했는데 없으면 거부하고, 동결 전 실행은 기본 위치에 동결 파일이 없을 때만 된다. workspace는 SKIP 집합(`.git`·build·experiment·에이전트 상태 등) 제외 복사 후 `git init` + 커밋 1개. manifest에 요청 모델·워커 모델·session id·volume 이름·시딩 해시·self-test 결과를 기록한다. 호스트 uid는 1000이어야 한다.
- self-test(무네트워크·무토큰 helper 컨테이너, 900초 상한): CLI 인자 수용 + init 이벤트의 tools 관측(모든 arm에 `WebSearch`·`WebFetch` 존재, 모든 arm이 자기 allow-list의 부분집합, 1·2번은 fan-out 도구 부재, 3번은 1·2번 목록 + `Task`이며 `Task` 존재), `/workspace` git toplevel 판독, 3번은 settings.json SHA 일치·참조 훅 전부 존재(8개 이상)·`bash -n`·시딩 파일(core.md·HISTORY.md·hooks·playbooks·templates·agents) sha256 재검증(검증기 실패도 실패)·추가 파일 부재, gate-guard에 합성 PreToolUse Write(L1 exit 2 / docs exit 0)와 Bash(양성 3훅 exit 0 / 상태파일 tee exit 2 / push → ask), `fable-review` 존재·`bash -n`, 리뷰어 도우미(`lab-arm3-start`·`fable_review.py`·계정 `fablereview` uid 2001) 존재(`reviewer_helper_present`). turn 직전(3번)에도 반복한다.
- turn: `docker create --cap-drop=ALL --security-opt=no-new-privileges --pids-limit=512 --cpus=2 --memory=3g --env-file <파일> --env HOME --env CLAUDE_CONFIG_DIR` + workspace bind + config volume(+3번 리뷰어 volume `/home/node/.fable-review`와 `LAB_REVIEWER_MODEL`·`LAB_REVIEWER_CONFIG_DIR`, `--user 0:0 --cap-add SETUID --cap-add SETGID --cap-add SETPCAP --cap-add DAC_READ_SEARCH` — 시작 스크립트만 쓰고 PM·리뷰어 CLI에는 남지 않음, 명령 앞에 `lab-arm3-start`) + `claude -p --verbose --output-format stream-json --model <m> --effort high --dangerously-skip-permissions --session-id|--resume <고정>` (+`--tools <allow-list>` — 3번은 1·2번 목록 + `Task`, 3번 `CLAUDE_CODE_SUBAGENT_MODEL`·`CLAUDE_CODE_SUBAGENT_EFFORT=high`). 재개 턴은 `--kind`(feedback·answer·recovery)를 선언해야 하고(없으면 호출 전 거부, `answer`는 3번만) 종류는 `invocation.json`의 `turn_kind`에 남는다. 피드백 상한 30은 성공한 `feedback` 전달(그 `recovery` 포함)만 센다(`docs/runbook.md` 상한 절). `recovery` 턴은 이어 가는 턴의 `prompt_sha256`과 같은 프롬프트만 받는다. `--max-budget-usd`는 0 이상의 유한수만 받는다. 호출 전 run 상한 게이트(`limit_gate`)를 지나고 timeout은 남은 시간으로 줄인다. prompt는 stdin. 종료 후 마스킹된 inspect·`projects/` transcript 사본·(3번) 리뷰어 호출 로그와 transcript(`reviewer-calls.log`·`reviewer-projects/`)를 복사하고 `events.jsonl`·`events.role-*.jsonl`·`result.json`을 만든 뒤 컨테이너만 제거한다. run 디렉터리 전체 토큰 스캔에서 히트가 나오면 실패.
- result.json 주요 필드: `result`(턴의 result 이벤트를 합친 값 — 네 카운터는 합, `total_cost_usd`·`modelUsage`는 세션 누적이라 마지막 값; 이벤트별 원본은 `results`), `session_id_confirmed`, `request_ids`, `event_count`, `incomplete`, `transcript_stats`, `usage_complete`, `usage_cross_check`, `role_files`, `transcript_models`, `roles`, `config_volume`(파일 목록·credentials 여부), `cost`, `reviewer`(호출·비용), `observed_tools_and_effort`, `secret` 히트는 `SECRET-LEAK.txt`. run 디렉터리의 `ledger.json`이 전 역할 단일 장부, `censored.json`이 상한 도달 기록이다(`first.when`: before/after call, `first.call`: `turn`|`user-proxy`).

## 검증

단위테스트(`python3 -m unittest discover -s payment-settlement/claude/runner`, 실행 시점 개수는 출력의 `Ran N tests`가 정본): 마운트·환경변수·플래그 구성, arm 3 요구사항, 원자 init·덮어쓰기 거부·git init, 하네스 시딩 해시, env-file 검증(권한·단일 키·repo 밖), stream 파싱, requestId 사본 일치·역할·incomplete, inspect 마스킹·스캔, dry-run 무실행, 토큰 유출 시 실패. 실제 인증·resume·훅 발화·서브에이전트 모델 전파는 유료 스모크 증거(`docs/results/setup/claude/`)가 필요하다.
