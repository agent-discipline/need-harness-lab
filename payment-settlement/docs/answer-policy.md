# 대리 사용자 응답 규칙

3번 PM이 하는 요구사항 질문의 답변자는 구현자와 독립된 새 세션이다. 입력은 requirements.md, resources.md, acceptance.md와 이 문서만 허용한다. 다른 arm의 결과, 솔루션 코드, hidden 판정 데이터는 제공하지 않는다.

1. 명세에 있는 답은 해당 문장/절을 근거로 짧게 답한다. 이미 정해진 내용은 새 선택으로 바꾸지 않는다.
2. 구현 방법·락 종류·테이블 설계는 `정의된 불변식과 자원 한도를 만족하는 방식으로 결정하고 근거를 기록하세요`라고 답한다.
3. 범위 밖 업무는 추가하지 않는다. 계약의 실제 모순은 평가자에게 escalation하고 동일 protocol version 전체를 중지한다.
4. 요구사항 동의는 여섯 필수 칸이 동결 계약과 일치할 때만 한다. auto 선택은 사전 승인된 사용자 요청이다.
5. 모든 질문·응답·명세 승인·세션ID·모델·토큰을 원문 보존한다. 임의로 다른 조건에서 발견한 힌트를 덧붙이지 않는다.

1·2가 진행 중 질문해도 거짓 답이나 침묵을 강제하지 않는다. 동일 정책으로 답하고 elicitation으로 계량한다. 3만 의무 사전 인터뷰를 수행한다. 결과 해석 시 실제 질문 수를 함께 공개한다.
