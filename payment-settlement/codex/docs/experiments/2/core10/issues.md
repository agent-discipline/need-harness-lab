# 구현 문제 기록

상태: NOT_STARTED. 아직 실행하지 않았으므로 문제 없음으로 판정하지 않는다.

문제마다 아래 항목을 작성하고, 해결되지 않은 항목도 보존한다. 다른 독립 시행의 해결 내용을 구현 에이전트에게 전달하지 않는다.

## ISSUE-001 — <문제 제목>

- 상태: OPEN / INVESTIGATING / RESOLVED / UNRESOLVED
- 발생 시각 / 단계 / 프롬프트 번호:
- 발생 상황 및 기대 결과:
- 실제 결과 및 영향:
- 증거: 원본 로그 경로, 명령, exit code, 코드 위치
- 원인: 확인된 사실 / 추정 / 미확인 구분
- 해결 방법: 시도별 변경 및 실패한 시도 포함
- 해결 후 검증: 명령, 결과, 증거 경로; 미실행이면 미실행 표시
- 연결 기록: transcript 번호, 수정 commit, 관련 ISSUE
- 추가 사용량: 연결된 turn의 usage; 전체 사용량에 중복 합산하지 않음

위 양식은 미작성 템플릿이며 실제 발생한 문제로 집계하지 않는다.
